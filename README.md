# Taiwan E-Commerce Data 台灣電商開放數據

由 [ECPRO 電商博士](https://ecpro.tw) 實測台灣 13 萬+ 網站產出的彙總統計，開放引用。

## 資料集

| 檔案 | 內容 |
|---|---|
| `platform-share.csv` | 台灣開店平台市佔（各平台網站數，實測偵測） |
| `industry-distribution.csv` | 台灣電商網站產業分佈 |

## 方法論

以 ECPRO 偵測引擎對台灣網域全量掃描（公開頁面技術指紋），彙總為統計數字；不含任何個別網站的私有資料。詳見 [方法論說明](https://ecpro.tw/about)。

- 更新頻率：不定期（隨全量重掃）
- 即時互動版：[台灣電商技術大調查](https://ecpro.tw/data)、[技術採用趨勢](https://ecpro.tw/trends)
- 程式取用：[公開 API](https://ecpro.tw/api-docs)、[MCP server](https://github.com/kewelin/ecpro-mcp)
